## About

VISIONOID は、ドローン・ロボティクス・AI を武器に、エンターテインメントから社会インフラまでを手がける Visionary Technology Company です。
失敗の許されないライブエンターテインメントの現場で鍛えた技術を、産業・防災・教育の現場へ。構想から設計・開発・運用までを一社で完結させます。

> **Mission** — 人の心を動かす「技術」で、「社会」を前に進める。<br>
> <sub>MOVE SOCIETY WITH TECHNOLOGY THAT MOVES HEARTS</sub>
>
> **Vision 2030** — 技術と創造力で、社会の可能性を拡張する。

## Origin

2017 年に発足したプロドローンレーシングチーム **JAPRADAR** が母体です。
レースで鍛えた操縦・機体技術を引き継ぎ、2024 年に VISIONOID としてエンターテインメント・産業・防災への社会実装を始めました。
